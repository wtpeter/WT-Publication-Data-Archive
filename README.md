# Tai Wang’s Publication Data Archive

This repository collects code, calculation inputs and outputs, and records of selected data-processing steps for publications mainly (co-)authored by Tai Wang (<wtpeter@pku.edu.cn>). Each entry links to a directory with its own README, either here or in a separate repository.

For some of the earlier studies, records of software versions, script changes, and data-processing steps are incomplete. These gaps in the records are unlikely to affect the papers’ scientific conclusions. Tai Wang prepared this archive, takes responsibility for its contents, and welcomes corrections.
